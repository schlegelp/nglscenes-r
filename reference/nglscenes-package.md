# nglscenes: Generate and Manipulate Neuroglancer Scenes

Construct, parse, edit and combine 'neuroglancer' scenes (viewer
states). Scenes can be read from URLs (including state servers), JSON
strings, files or the clipboard; layers, segments, colours and
annotations can be manipulated; and scenes can be written back to URLs,
JSON, files or the clipboard. Also creates 'neuroglancer' segment
properties. R port of the core of the Python package 'nglscenes'.
